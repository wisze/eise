# Eise

Dese repo bevat scripts om de sterren en planeten te laten zien. Tot nu toe zijn
het de volgende:
* [Eise](eise.md) De eerste, waar de repo zijn naam van heeft. Een python
  script om de sterrenhemel met de positie van de planeten te laten zien
  op een raspberry pi mini met een klein e-ink scherm.
* [Ptolemeus](ptolemeus.md) De middeleeuwse blik op de hemel. Ook voor
  een raspberry pi met een pimoroni inky e-ink scherm.
* [Planisfeer](planisfeer.md) De hele hemel getekend als een planisfeer, maakt
  een SVG file voor een plaats en tijd.
* [Comets](comets.md) maakt alleen een file met kometen die door het planisfeer
  script gebruikt worden. Maakt een shortlist van kometen op niet als te grote
  afstand van de Aarde.
* [Cirkels](cirkels.md) is een hulpscript wat een tekening maakt van een
  planeetpositie op zijn epicirkels om het ptolemeus script te checken.

## Mappen en files

* /pics bevate de plaatjes, voorbeelden, screenshots die in de leesbare
  teksten gebruikt worden.
* /marginalia bevat alleen de plaatjes die door het ptolemeus python script
  gebruikt worden om in de marge linksonder te zetten. De plaatjes moeten
  een doorzichtige achtergrond hebben. De plaatjes in de directory zijn met AI
  gemaakt.
* /lib bevate de files voor de lettertypen die gebruikt worden in de scripts.
  Eise gebruikt het astro lettertype voor de planeetsymbolen.
  Het ptolemeus python script gebruikt een out-duits lettertype Schwabacher,
  een lettertype voor de intiaal en een lettertype voor de symbolen van
  de sterrenbeelden..
